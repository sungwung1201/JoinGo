GATED + COLOR 
[스캔 중 ROS/Python 노드가 쓰는 경로]
twin_state/site_joingo_lab_001/current_inspection/capture_id      : 저장 완료된 캡처 ID
twin_state/site_joingo_lab_001/current_inspection/3d_scan_done    : false → 스캔 중, true → 스캔 완료
twin_state/site_joingo_lab_001/current_inspection/scan_status     : SCANNING | DONE | ERROR 등 선택 필드
inspections/site_joingo_lab_001/captures/{capture_id}             : 완성된 3D 캡처 데이터
  ├─ metadata
  ├─ summary
  ├─ markers
  ├─ storage_refs/background_light_url     : 권장, 색상 유지/다운샘플된 경량 배경
  └─ storage_refs/background_url           : fallback, 원본 배경

[웹이 실시간으로 계속 구독하는 경량 경로]
twin_state/site_joingo_lab_001/current_inspection                 : capture_id, 3d_scan_done, summary 정도만 수신
exceptionstatus/current                                           : 예외상황 팝업
exceptionstatus/history                                           : 예외 이력
events/site_joingo_lab_001                                        : 검사 완료 이벤트

[웹이 무거운 데이터로 판단하고 상시 구독하지 않는 경로]

background_url 원본 Point Cloud 상시 reload X
