검사 화면 보기

RGB 화면과 viewer_05.html 기반 실시간 3D 단차 모니터링 화면을 같은 웹 안에 표시합니다.

3D VIEW

viewer_05.html과 이 파일을 같은 폴더에 두면 실시간 3D 단차 모니터링 화면이 iframe으로 표시됩니다. viewer_05는 linestatus의 최신 회차, markers, background_url을 직접 구독합니다. RGB가 html이면 iframe, mp4/webm/ogg면 video로 표시합니다.

ROSBridge 통신

ROS에서 받은 linestatus JSON을 화면에 표시하고 DB의 linestatus 로그로 저장합니다.

ROS OFFLINE 
ROS 이벤트 로그가 여기에 표시됩니다.\n수신 메시지 예시:\n{\n  "linenumber": 1,\n  "time": 1770000000000,\n  "screw": {\n    "1": {"position":"S01", "status":"normal", "torque":2.50},\n    "2": {"position":"S02", "status":"defect", "torque":1.82}\n  }\n}

Firebase linestatus 테스트

불필요한 joingo/lineStatus, joingo/screwLogs, joingo/commands 없이 linestatus만 사용합니다.
